# 军队文职岗位查询采集器

一个 Tampermonkey 用户脚本。在军队人才网「岗位查询」页面一键抓取**全部页**岗位数据，按岗位代码去重累积，导出 Excel 可直接打开的 CSV。

## 为什么需要它

2027 年度军队文职人员公开招考**取消了岗位表 Excel 附件**，岗位只能在报名系统里一页一页在线翻——每页 10 条，全国 14971 个岗位就是 1500 页。想按专业、省份、学历筛一遍，基本没法手动做。

这个脚本把页面自己用的那个查询接口找出来，直接在浏览器里把每一页的数据批量拉回来。

## 它做什么

| 动作 | 说明 |
|---|---|
| 后台抓全部页 | 按当前筛选条件，逐页请求接口，全量入库。页面全程不刷新 |
| 采集本页 | 只抓当前显示的这 10 条，作为兜底 |
| 导出 CSV | 导出整个库存（不是当前页），UTF-8 BOM，Excel 双击不乱码 |
| 去重累积 | 按岗位代码去重，存在 localStorage。换条件、换省份再跑会合并，不重复 |
| 诊断 | 出问题时打印页面变量、筛选条件、接口返回，便于定位 |

24 个字段全部保留，包括页面不显示但数据里有的 `是否免笔试直接面试` 和 `是否先面试后笔试`。

## 它不做什么

- **不代替你报名**，不发任何写操作请求，只读
- **不绕过登录**，仍需要本人账号登录（系统要求实名实人认证，需要本人身份证 + 人脸核验）
- **不保证数据完整**，一切以系统为准

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox / Safari）
2. 点 Tampermonkey 图标 → **添加新脚本**
3. **全选删掉**编辑器里的模板内容，粘贴 `jzwz-collector.user.js` 全文
4. `Ctrl+S`（macOS 是 `Cmd+S`）保存
5. 打开岗位查询页，右下角出现「⚡ 岗位采集器」面板即成功

## 使用

```
1. 在页面上勾好筛选条件  →  点「查询」，等结果表出来
2. 点「后台抓全部页」
3. 看面板进度跑完（1348 条约 135 页，2 分钟左右）
4. 点「导出 CSV」
```

**第 1 步的「查询」不能省。** 脚本复用页面自己的 `cxCollect()` 取筛选条件，你在下拉框里改了但没点查询，脚本拿到的还是上一次的条件。

抓取过程中**不要刷新页面、不要关标签页**，否则中断。已经抓到的数据不会丢，重新点一次会从第 1 页重跑并自动去重合并。

## 工作原理

页面翻页不是整页提交，而是走 ajax：

```js
$.post(CX_CTX + '/stuchooseexam/querykspoFullByAjax.htm', p, function (zwdata) {
  var sjs = zwdata.zzpoList.data.list;  // 当前页的行数据
  CX_ROWS = sjs;
  // 表格由前端用 sjs 拼出来
});
```

所以：

- 服务端返回的 HTML 里**没有** `<tbody id="kslist">`，它只出现在一段 JS 字符串拼接代码里。想靠 curl / POST 表单拿表格数据的思路走不通。
- 筛选条件不在 `<form>` 里，而在页面 JS 的变量里，由 `cxCollect()` 读取。
- 分页靠 `p` 里的 `page` 参数，不是表单的 `requestPage`。

脚本直接调这个接口，拿 `zzpoList.data.list` 的原始 JSON，因此不需要解析 HTML，也不受页面刷新影响。

`@grant none`，脚本运行在页面上下文，可以直接访问 `window.cxCollect` / `window.CX_ROWS` / `window.CX_CTX`。

## 常见问题

**面板没出现**
确认 URL 是 `wzryzk.81rc.mil.cn/qjwzwb/stuchooseexam/viewPosition.htm`。面板只在岗位查询页注入，其他页面不显示。

**抓取很慢 / 中途频繁失败**
页面自带频率限制（`cxOpAllowed()`）。调大脚本顶部的 `DELAY_MIN` / `DELAY_MAX`（比如 1500 / 2500），连续失败 5 页会自动停止并保留已有数据。

**提示「返回不是 JSON（可能登录已失效）」**
会话超时了。回登录页重新扫码，再走一遍流程。

**导出的中文是乱码**
用 Excel 直接双击打开应该正常（已加 BOM）。如果还是乱，用「数据 → 从文本/CSV 导入」并指定 UTF-8。

**换筛选条件会不会把之前的数据冲掉**
不会。库是按岗位代码累积的，跑完吉林再跑广东，两边都在，导出时一次性全给。

**数据存在哪，会不会丢**
浏览器 localStorage，键名 `jzwz_gw_db_v2`。清理浏览器数据 / 换浏览器 / 无痕模式会丢。**每轮跑完立刻导出一次 CSV**，这是最稳的。
